# Isadora Melo — prévia conceitual

Site estático, em HTML/CSS/JS. Abra index.html ou publique a pasta inteira no GitHub Pages. Todos os caminhos dos recursos são relativos, compatíveis com publicação em subdiretório.

Fontes de informações profissionais consultadas: https://www.psymeetsocial.com/psicologo/isadora-santos-melo e https://ecocard.bio.br/diretorio/se/aracaju/psicologa-isadora-melo. Imagens fornecidas pela desenvolvedora. Textos institucionais e identidade tipográfica são propostas editoriais, sujeitas à aprovação. O símbolo vegetal é conceitual, não uma reprodução da marca oficial. Sem valores, depoimentos, endereço preciso, horários ou promessas de resultados. A modalidade presencial não foi afirmada sem confirmação. O link do Canva não pôde ser acessado; a correspondência de cores com a marca precisa ser validada.

A prévia está marcada como não oficial e contém noindex/nofollow. Após aprovação para publicação definitiva, retirar a nota de prévia, atualizar robots para index, follow e confirmar modalidade, contatos, identidade visual e conteúdo. Google Fonts tem fallback local; não há dependência de framework.
